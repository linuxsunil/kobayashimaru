# PR Firestorm 🌪️ — The Kobayashi Maru Experiment

> "Trace it back far enough and the human disappears. That's the problem."

**PR Firestorm** is a weekend project exploring the "no-win scenario" in modern corporate communications. Using Gen AI, the simulator creates a high-pressure environment where every public statement leads to a calculated "outrage" from conflicting stakeholders.

## 🖖 The Philosophy
Inspired by the *Kobayashi Maru* (the unwinnable training simulation from Star Trek), this tool moves away from "win-win" frameworks. In an era of trade wars, climate crises, and AI regulation, every option has a real cost. This project tests how you navigate that tension.

## 🛠️ Tech Stack
This is a **Learning-as-Code** project built entirely as a single-file, LLM-agnostic application.
* **Frontend:** Vanilla HTML/CSS/JS with a "Command Center" aesthetic.
* **Orchestration:** Multi-Persona System Prompting.
* **AI Providers:** Compatible with **Claude (Anthropic)**, **Gemini (Google)**, and **GPT-4o (OpenAI)**.

## 🚀 How to Play
1. **Clone the repo.**
2. **Open `index.html`** in any modern browser.
3. **Set your API Key.** (Your key is used only for direct browser-to-LLM calls and is never stored).
4. **Draft your apology.** You are the CEO of a company whose AI hiring tool just discriminated against 14,000 candidates.
5. **Release the statement.** Watch as three AI personas (Shareholder, Activist, and Employee) analyze your statement through completely different lenses.

## 🧠 What it Teaches
* **Persona-based Prompting:** How different "system instructions" interpret the same data.
* **Sentiment Analysis:** How AI can simulate human outrage and social friction.
* **Strategic Communication:** The reality that you cannot please everyone.
